# An Update of Service and Network YANG Data Models
 
This is the working area for the individual Internet-Draft, "An Update of Service and Network YANG Data Models". This document reports the findings from implementations of the service and network data models, including missing functionalities, alignment of configuration blocks with recently published network models, operational issues and limitations, and enhancements.

# A Common YANG Data Model for Layer 2 and Layer 3 VPNs
 
This is the working area for the individual Internet-Draft, "A Common YANG Data Model for Layer 2 and Layer 3 VPNs". This document updates the common YANG data models for L2 and L3 VPN provisioning (RFC 9181) to address gaps revealed by implementations in network controllers.
